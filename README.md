# x2d接入动物车辆模型识别 测试版

适配机型为哈苏 X2D 100C，固件 4.2.0。本次测试版本为 r22l-fix3。

在对焦点菜单中可以选择人物、动物、车辆或关闭识别。前后拨轮逐格浏览，按下后拨轮确认。持续追焦采用 4 次位置平滑窗口，当前目标合焦后显示完整绿色识别框。

## 验证记录

- fix2 在相机进程中读回 4 次位置窗口。用户确认合焦即显示完整绿框，持续追焦时显示正常。
- fix3 通过 69 组离线检查，用户实测拨轮能够选中目标模型。
- fix3 撤回后经冷启动核验，原厂识别服务、10 次位置窗口和原厂 USB 均已恢复。
- 猫狗户外识别质量与追踪延迟的毫秒数仍待实测。
